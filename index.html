About

My path into security started in software. I built full-stack MERN and blockchain-enabled web applications at Devsinc, which taught me how real applications are designed, shipped and broken. I then moved into enterprise operations at Allied Bank Limited, where I keep mission-critical banking applications secure, available and compliant every day.

That mix shapes how I work: I treat security as an engineering property that belongs inside the pipeline, not a checkpoint at the end. My home projects automate scanning, policy and deployment so that the secure path is also the easiest path.

Alongside the day job I have completed the APIsec University API Penetration Testing course, the AIG and ANZ security simulations, and a series of cloud-based SIEM, vulnerability management and malware analysis labs.
